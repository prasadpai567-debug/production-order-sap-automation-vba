# Screenshot guidance

No screenshots are currently included in this public repository.

If screenshots are added later, use only synthetic or fully redacted data. Recommended views are:

1. Launcher sheet with the documented buttons.
2. Batch Summary showing synthetic batch-to-process-order validation.
3. Material Detail showing synthetic material, phase, batch, quantity, and comparison-result columns.
4. COR6 Run Log showing synthetic processed, skipped, and error states.
5. SAP Data showing a synthetic MB51-style output.

Before publication, remove or mask process orders, material numbers, material names, quantities, batch numbers, storage locations, dates, usernames, status-bar text, file paths, company branding, and any SAP server/session details.

Do not capture or upload live SAP screens, production workbooks, supplier data, or operational logs.
