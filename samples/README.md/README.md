# Synthetic sample guidance

No workbook samples are currently included in this public repository.

A future sample package may include a synthetic recovery workbook and a text-based expected-output example, but only after the file contract and publication permissions have been reviewed.

Synthetic samples should:

- use clearly fictional batch, process-order, material, quantity, date, and storage-location values;
- demonstrate both passing and checking validation states;
- demonstrate a material match and a material-not-found state;
- avoid real company names, supplier information, internal paths, SAP identifiers, or production quantities;
- be labeled as synthetic and not suitable for production use.

A sample file must not be used as evidence of live SAP connectivity or successful COR6 posting.
